## 改进方向

1. 在 1 CPU 限制下实现更快的位棋盘 Python MCTS（减少 flood fill 与对象分配）；
2. 用 KataGo 离线生成更大规模的策略/价值训练集，蒸馏为纯 Python 轻量策略；
3. 逐手复刻与 MCTS 的自适应切换：基线偏离胜局时立即切换搜索，而不是继续查表；
4. 收官阶段以实际数子差为目标做终局搜索，避免 0.25 子级别的损失。
